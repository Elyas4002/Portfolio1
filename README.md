# Sakhizai Portfolio (React + Vite)

Stack: React, Vite, Tailwind CSS v4, Framer Motion, Lucide React.

## Run
```bash
npm install
npm run dev      # development server
npm run build    # production build into dist/
npm run preview  # preview the build
```

## Fill in the placeholders
- `src/data.js`: GitHub and LinkedIn URLs (`SOCIAL`), project repo URLs (`repo`), and verify each project's description, technologies and features.
- Screenshots: add `public/screens/<id>.png` (ids: course-cards, task-grid, form, basic-website). Until then a labelled placeholder shows.
- `src/components/Sections.jsx`: certifications placeholder in About.
- The contact form opens the visitor's email app (mailto). For server-side delivery, connect a service such as Formspree or Netlify Forms.
